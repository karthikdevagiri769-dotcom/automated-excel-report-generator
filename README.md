# Automated Excel Report Generator

A Python-based business automation tool that processes Excel sales data and generates reports automatically.

## Features
- Reads sales data from Excel files.
- Calculates total revenue.
- Identifies the best-selling product.
- Calculates total transactions.
- Identifies the highest-value sale.
- Generates an output Excel report.

## Technologies Used
- Python
- Pandas
- OpenPyXL
- Microsoft Excel

## Installation

Install the required libraries:

```bash
python -m pip install pandas openpyxl
```

## How to Run

1. Download or clone this repository.
2. Place `sales_data.xlsx` in the project folder.
3. Run:

```bash
python main.py
```

4. The generated report will be saved as `sales_report.xlsx`.

## Project Purpose

This project demonstrates how Python can automate repetitive business reporting tasks and reduce manual Excel work.
